## ✦ Lumi Transport 2.1

**Unduh:** `LumiTransport-v2.1.apk` di bagian *Assets* di bawah. Pasang langsung di atas 2.0.

### 🔎 Cari alamat langsung di dalam aplikasi

Dulu setiap alamat harus dicari di Google Maps lalu dibagikan balik ke Lumi. Sekarang ketik saja:

- **Ketik ≥ 3 huruf** di kolom asal atau tujuan → saran alamat muncul langsung, tanpa keluar aplikasi
- Sumbernya **OpenStreetMap (Photon)** — gratis, tanpa API key
- Hasil disaring ke **Indonesia** dan dibias ke **Jabodetabek**, jadi "monas", "blok m", atau "stasiun manggarai" langsung menemukan tempat yang benar
- Pilih salah satu saran → titik asal/tujuan terisi, rute langsung dihitung

**Alur lama tetap ada:** baris "Cari … di Google Maps" masih paling atas. Untuk alamat yang tidak ada di OSM (gang kecil, nama gedung baru), pilih tempat di Google Maps lalu **Bagikan → Lumi Transport** — koordinat dari teks yang kamu bagikan tetap dibaca seperti biasa.

### 📦 Build dan rilis

- Build berpindah ke **Gradle 8.7** dengan **version catalog** tunggal (`gradle/libs.versions.toml`)
- **R8 + `shrinkResources`** aktif untuk rilis, dengan aturan keep khusus jembatan `LumiNative` agar WebView tidak kehilangan method-nya
- Setiap PR sekarang menampilkan **ukuran APK** dan dibangun dua jalur (Gradle dan skrip lama) sebagai pembanding
- Rilis APK diambil dari build Gradle

### 🔧 Perbaikan teknis

- **User-Agent tunggal** diambil dari `versionName` (`LumiTransport/2.1 (Android)`), dipakai WebView dan semua permintaan HTTP. Sebelumnya UA ditambahkan dua kali dengan versi berbeda
- `versionCode` **20100** (`2.1`)
- `minSdk` 26 (Android 8.0+)
