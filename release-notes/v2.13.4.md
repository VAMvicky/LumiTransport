## ✦ Lumi Transport 2.13.4

**Unduh:** `LumiTransport-v2.13.4.apk` di bagian *Assets* di bawah. Pasang langsung di atas versi sebelumnya.

Rilis perapian dari hasil audit kode.

### 🗺️ Data rute & halte

- **Data rute resmi Transjakarta kini ikut di dalam aplikasi.** Sebelumnya 120 dari 251 rute bawaan belum punya daftar halte sampai data resmi berhasil diunduh. Sekarang semua rute langsung lengkap sejak pertama dibuka, termasuk di HP yang gagal mengunduh
- **Titik halte & stasiun lebih tepat**: koreksi dari OpenStreetMap dipakai langsung di data bawaan (mis. stasiun LRT Pancoran, Matraman, Kuningan, JIS yang sebelumnya meleset 300–650 m)
- Peringatan "tidak beroperasi" hanya muncul bila memang seluruh moda itu tutup. Sebelumnya, satu bus wisata yang belum buka pukul 08.00 membuat "Transjakarta non-BRT" seolah tutup

### 💸 Tarif

- Semua tarif kini ada di satu file data dan **bisa diperbarui dari repo tanpa rilis baru**. Data yang diunduh diperiksa dulu sebelum dipakai

### 🛡️ Lebih tahan gangguan

- Bila server peta (OpenFreeMap) tidak menjawab, Lumi otomatis beralih ke peta OpenStreetMap standar
- Server pihak ketiga (rute jalan kaki, pencarian alamat) yang sedang bermasalah diistirahatkan sebentar supaya aplikasi tidak menunggu terus dan langsung memakai cadangan
- Umpan perubahan rute dan koreksi titik halte dari GitHub diperiksa bentuk & ukurannya sebelum disimpan
- **Laporkan masalah** kini melampirkan galat terakhir (aplikasi & crash Android), supaya bug lebih cepat diperbaiki

### 🎨 Tampilan

- Layar sambutan tidak lagi tertimpa tombol *Mulai* di layar yang pendek
- Judul hasil pencarian tidak lagi terjepit menjadi satu kata per baris
- Ikon bertema (Android 13+) untuk layar utama

### 🔧 Catatan teknis

- APK hanya dibangun lewat Gradle (R8); `build.sh` dihapus. Android lint aktif di CI
- CI menjelajahi semua layar di Chrome dan gagal bila ada galat JavaScript atau teks yang belum diterjemahkan ke Inggris
- Semua GitHub Actions dikunci ke SHA commit
- `versionCode` **21304**
